# 0.1.0 状态与后续计划

这是面向单创作者的本地 MVP。工作台支持实际使用，但未完成生产公网部署验收。

## 已交付

- GitHub 导入、主题发现、四项中文介绍及最多三项比较。
- 原文来源与亮点复核；四段口播及配套文案的生成、编辑、采用、确认和版本留存。
- 本人音色创建、试听、复用、命名和列表批量移除；完整配音与实际时长检查。
- 固定稿件版本素材包导出，以及临时包到期后本地重打包。
- 24 个内置精选工具 Bot，工具介绍与链接；榜单草稿、发布副本与下架同步。
- 会话恢复、窗口配对、任务归档与回收站、费用预算和失败结果留存。

## 已有真实验证

GitHub 资料、Qwen 分析/写作和 CosyVoice 真实调用已接入。一个创作任务完成了人工资料与稿件复核、33.94 秒本人克隆音试听采用，以及包含口播、文案、音频和版本说明的 ZIP 导出。

这不代表所有模型输出均合格，也不代表全部 PRD 质量样本完成。模型生成与人工修订分开记录；工具摘要的来源引用可追溯，但不能证明语义一定准确或对应产品已被亲测。

## 尚待验证或完善

- 更多真实工具的文本质量样本、至少五段真实配音及跨任务复用的完整质量验收。
- 最新整批摘要的真实质量、生成延迟和调用成本。目前已验证工程流程与既有资料展示。
- 手机真机、读屏体验与 Bot 在普通移动网络和设备上的性能；桌面模拟窄屏不能代替真机。
- 抖音手动发布的实时平台规则。输出仍为创作草稿，需要发布前自行核对。
- 历史未知账单及跨本地、OSS、供应商和备份的完整留存清理；本地操作不等于供应商已删除。
- 生产环境部署、备份恢复、回滚、域名/HTTPS 和持续运行管理。

## 首版范围之外

自动运行 GitHub 项目、自动录屏剪辑、字幕封面、数字人、自动发布、多创作者 SaaS 注册和付费会员。MIT 开源不包含供应商 API、OSS 或其他第三方服务的费用。
