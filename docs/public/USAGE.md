# 使用与运行

## 从工具到素材包

1. 打开“创作任务”：已有仓库时点击“导入 GitHub 链接”并填写地址；没有目标时点击“寻找下一个工具”。
2. 在“发现工具”按主题寻找，阅读四项中文介绍，选择最多 3 项比较。真实模式的新搜索如需模型摘要，会先请求费用确认；取消仍保留候选。
3. 选定工具后导入。处理完成点击“查看资料”，阅读来源片段，再点“分析功能与亮点”。
4. 分析完成后选择主推亮点，可选辅助亮点；对照原文确认示例与条件，再创建任务。来源不完整时不要把资料推测写成亲测结论。
5. 在任务中生成口播与文案，编辑、采用并分别确认。四段结构为“痛点 → 固定栏目句 → 核心亮点 → 使用示例”。保存会保留版本，旧音频或文案可能因稿件变化需要重新确认。
6. 在“我的声音”建立并试听自己的音色，或选用已有可用声音。真实样本和签名 URL 配置见 [真实服务配置](CONFIGURATION.md)。
7. 在任务的“配音与素材导出”选择音色，预览合成文字，确认费用后生成完整配音。实际时长需为 30–35 秒，仍需人工试听检查漏读、读音和自然度。
8. 采用合格音频并确认同稿文案后导出 ZIP。视频剪辑与实际发布在外部完成。打包已有素材不调用模型。

## 记录与删除

- 任务支持归档、回收站和恢复；回收期 7 天，到期由 worker 根据引用与状态清理。
- 声音列表“移除”用于隐藏记录，不等于删除供应商音色、录音或既有配音文件。
- 处理记录用于查看结果、失败原因和继续操作。未知结果不自动重发，先核对原作业及供应商账单。
- 临时 ZIP 默认 24 小时清理，可按已保存版本重新打包；正式正文与配音不会随临时 ZIP 一起删除。
- 内置 24 个工具属于工作台展示目录。自己的榜单条目需要单独发布才会出现在 `/display`。

## 运行与恢复

API、worker 和 Web 都需要运行。停止服务时在相应终端按 Ctrl+C；关闭浏览器不会停止后台作业。启动前确认 8010、3060 没有被其他应用占用。

保持使用 `127.0.0.1`，不要和 `localhost` 混用，登录 Cookie 与 Origin 按地址区分。手机上的 `127.0.0.1` 指手机自身，本版快速启动地址只能在本机访问。

数据库位于 `data/ai_hexing.db`，素材与检查点位于 `data/` 下。遇到故障不要删除整个目录重建。升级已有实例前停止 API 和 worker，备份整个 `data/`，在副本上验证迁移；恢复时需保持数据库与对应素材、检查点一致。生产备份恢复方案尚未完成验收。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 一直排队 | 确认 worker 正在运行，查看处理记录里的具体状态 |
| 只有模拟音 | 默认 `PROVIDER_MODE=mock`；这验证流程，不是真实克隆。真实模式需配置并重启 API/worker |
| 另一窗口没有登录 | 使用工作台的“窗口连接”流程，勿分享密码或随意批准未知窗口 |
| MP3 上传失败 | 当前本地入口仅校验 WAV；需要先在外部转换，不能仅修改扩展名 |
| 超预算或价目过期 | 查看费用说明和当前配置；需核实新价目，不能自动绕过保护 |
| 不能完整导出 | 核对当前稿、同稿文案、音频采用状态和音频时长；修改稿件后旧配套素材需更新 |
| 删除后远端素材还存在 | 本地列表移除、本地文件清理、OSS 和供应商音色删除是不同操作 |

## 安装与统一启动

推荐从根目录运行 `python3.11 scripts/setup.py`。它检查 Python / Node、安装依赖、仅在 `.env` 不存在时创建默认 mock 配置，再执行数据库迁移。重新安装不会重置账号或覆盖配置；升级前请备份已有数据库。

首次安装后运行 `.venv/bin/python -m backend.app.cli create-owner` 创建自己的账号；然后 `python3.11 scripts/start.py` 启动 API、worker 和 Web。看到 Ready 后访问 `http://127.0.0.1:3060/discover`。按 Ctrl+C 可停止全部服务。该启动器固定使用文档中的本地端口；自定义部署请使用下列独立服务命令并调整前端代理与 origin。

手动启动（分别运行于三个终端）：

```bash
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8010 --no-access-log --no-proxy-headers
.venv/bin/python -m backend.app.worker
npm --prefix frontend run dev -- --hostname 127.0.0.1 --port 3060
```

## 邀请访客只读浏览

工作台只有一个创作者账户。想让别人看你的工作台时，生成邀请码发给对方：

```bash
.venv/bin/python -m backend.app.cli create-invite --label "发给谁"   # 默认 30 天，可多次使用；--days 改天数
.venv/bin/python -m backend.app.cli list-invites                     # 查看状态和使用次数
.venv/bin/python -m backend.app.cli revoke-invite --invite-id <ID>   # 作废，已登录的访客立即退出
```

邀请码只在生成时显示一次。访客在登录页「用邀请码访问」输入后，看到的是你的发现工具、创作任务和工具封神榜，可浏览稿件、播放正式配音和下载导出包；不能修改或生成任何内容，看不到我的声音、费用记录、处理记录和接入设置，也拿不到录音样本。访客会话最长 8 小时，且不超过邀请码到期时间。

访客不能发起付费调用，全部费用都受 `.env` 中你的每月上限约束（默认 30 元）。对外开放前另见 [配置说明](CONFIGURATION.md) 的「登录限流」。

## 本机完整演示

面试或本地讲解时，用隔离的模拟工作台，带已走完的示例任务，不读写正式数据库，也不调用付费服务：

```bash
python3.11 scripts/setup.py    # 只需一次，已安装可跳过
python3.11 scripts/demo.py     # 写入示例后启动；--reset 会清空 data/demo 再写一遍
```

Web 显示 Ready 后打开 **http://127.0.0.1:23060/discover**。终端会打印登录账户、密码和访客邀请码。演示占用 23060（Web）和 28060（API），与日常的 3060 / 8010 以及 QA 端口分开。

预置内容：Sketchbook 已确认口播、文案、正式配音和导出包；Ollama 已确认文稿；「健身」主题下有 3 条发现结果；两个榜单草稿。配音是模拟测试音。按 Ctrl+C 停止本次演示进程。
